# Assets — รูปภาพตัวละคร

เก็บรูปตัวละครของการ์ดไว้ในนี้ แยกโฟลเดอร์ตามเรื่อง (series)

## โครงสร้าง

```
assets/characters/
  naruto/        รูปจากเรื่อง Naruto
    naruto-uzumaki.webp
    sasuke-uchiha.webp
  onepiece/      รูปจากเรื่อง One Piece
    monkey-d-luffy.webp
    roronoa-zoro.webp
  _placeholder/  ภาพชั่วคราว/ภาพแทนระหว่างยังไม่มีรูปจริง
```

## กติกาการตั้งชื่อไฟล์ (naming convention)

- ตัวพิมพ์เล็กทั้งหมด ใช้ `-` คั่นคำ ไม่เว้นวรรค ไม่ใช้ภาษาไทยในชื่อไฟล์
  - ✅ `monkey-d-luffy.webp`  ❌ `Luffy รูป1.png`
- หนึ่งตัวละคร = หนึ่งไฟล์ ชื่อไฟล์ = ชื่อตัวละคร
- เพิ่มเรื่องใหม่ = สร้างโฟลเดอร์ใหม่ใต้ `characters/` เช่น `characters/dragonball/`

## ข้อแนะนำเรื่องรูป

- **ฟอร์แมต:** `.webp` (ไฟล์เล็ก คมชัด) หรือ `.png` ถ้าต้องการพื้นหลังโปร่งใส
- **ขนาด:** แนะนำด้านละ ~600–800px (ช่องรูปในการ์ดเป็นแนวสี่เหลี่ยมเกือบจัตุรัส)
- **สัดส่วน:** จัตุรัสหรือแนวตั้งเล็กน้อย จะพอดีช่องภาพในการ์ด

## วิธีอ้างถึงรูปในหน้าการ์ด

ในไฟล์ `design/card-front.html` ช่องภาพให้ใส่ `<img>` ชี้มาที่ไฟล์ เช่น

```html
<img src="../assets/characters/onepiece/monkey-d-luffy.webp"
     alt="Monkey D. Luffy"
     style="width:100%; height:100%; object-fit:cover">
```

## ⚠️ หมายเหตุเรื่องลิขสิทธิ์

ภาพตัวละครจากอนิเมะ/เกม/ภาพยนตร์เป็นงานมีลิขสิทธิ์ของเจ้าของเรื่อง
การเล่นในกลุ่มเพื่อนเป็นการใช้ส่วนตัว แต่การอัปขึ้น repo สาธารณะคือการเผยแพร่
ถ้าไม่อยากให้ภาพลิขสิทธิ์ขึ้น Git ให้เปิดใช้ `.gitignore` (ดูหมายเหตุในไฟล์ `.gitignore` ที่ root)
