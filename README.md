# Card Game Project

โปรเจกต์การ์ดเกมสำหรับเล่นกับเพื่อนบนโทรศัพท์และคอมพิวเตอร์

## โครงสร้าง

```
design/
  card-front.html      หน้าการ์ดมอนสเตอร์ (เปิดในเบราว์เซอร์ได้เลย)
  card-front.dc.html   ไฟล์ต้นฉบับจากแคนวาสออกแบบ
```

## หน้าการ์ด

- ค่าร่าย (มุมซ้ายบน)
- ชื่อไทย / อังกฤษ
- ธาตุ: ไฟ น้ำ ดิน ลม แสง มืด
- ระดับความหายาก: Common, Rare, Epic, Legend
- กล่องความสามารถ + คำบรรยาย
- พลังโจมตี (Power) / พลังชีวิต (Health)
